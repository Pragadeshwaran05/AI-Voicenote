The AI VoiceNote application has been fully set up!

Here is the Phase 1 feature summary:
- **Professional Dashboard** with responsive layout.
- **Text input editor** with live character counting.
- **Local TTS implementation** using `pyttsx3`.
- **Text Insights panel** measuring words, characters, sentences, and read time.
- **Built-in Audio Player** that becomes visible after generation.
- **History** of generations stored via SQLite.
- **Configurable Voices and Speed**.
- **Dark UI mode** styled for a modern AI application.

You can stop the current background task by ending it in the terminal or using standard shortcuts.
